# topology_v6 archive

This directory preserves the exact `topology_v6` tables used by the released
`temporal_topology_aft_cross_split_consensus_v1` web artifacts.

The production web backend remains pinned to these tables through
`config/releases/temporal_topology_v6.yaml` until a complete topology_v7
training, held-out evaluation, artifact replay, and deployment validation have
all passed.

Do not describe topology_v6 as observed clinical data. It is the previous
synthetic/noisy augmented development cohort.
